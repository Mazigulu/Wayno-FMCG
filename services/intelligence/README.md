# Wayno Intelligence Service

Microservice providing machine learning predictions for FMCG inventory demand, churn prediction, and dynamic credit scoring for retail dukas.

## Key Capabilities
- **Duka Restock Predictor**: Historical frequency analysis recommending personalized reorder carts.
- **Dynamic Pricing Engine**: Automated margin and volume discounting based on depot inventory aging.
- **Wholesaler Reliability Scoring**: Computes fulfillment SLA confidence scores based on past preparation latency and stockouts.
