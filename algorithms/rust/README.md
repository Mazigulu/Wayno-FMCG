# Wayno High-Performance Algorithms (Rust)

High-throughput, safety-critical algorithms compiled to native binaries and WebAssembly (Wasm) for low-latency logistics execution.

## Modules
1. **VRP Solver**: Heuristic combinatorial vehicle routing solver handling 500+ daily deliveries in <10ms.
2. **3D Cargo Knapsack**: Motorbike & tricycle parcel packing algorithm verifying weight (kg) and spatial volume (L) thresholds before dispatch.
3. **Geohash Spatial Indexer**: Sub-second spatial clustering across Nairobi zones (Eastlands, Westlands, CBD, Industrial Area, Embakasi).
