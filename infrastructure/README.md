# Wayno Cloud Infrastructure & DevOps

Terraform configurations, containerized multi-service Docker definitions, and multi-environment deployment pipelines.

## Subdirectories
- `terraform/`: Infrastructure-as-Code modules for VPC networking, Cloud SQL PostgreSQL, Redis Cache, and Cloud Run / ECS clusters.
- `docker/`: Dockerfiles and multi-container `docker-compose.yml` for local development.
- `environments/`: Staging and Production environment definitions with secret manager bindings.
