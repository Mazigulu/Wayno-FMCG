# Wayno Test Suites

Automated quality assurance spanning end-to-end integration tests, API contract checks, and high-volume performance simulations.

## Test Categories
- `e2e/`: Full checkout-to-delivery lifecycle integration tests.
- `load/`: k6 load testing scripts validating sub-50ms search latency under 5,000 req/s.
- `chaos/`: Network partition and Redis failover resilience scripts.
