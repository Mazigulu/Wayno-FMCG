# Wayno Wholesaler & Depot Portal (Next.js)

Web application tailored for wholesale distributor staff, depot managers, and inventory controllers.

## Core Features
- **Real-Time Fulfillment Queue**: Live dispatch board tracking orders across `PAID`, `PREPARING`, `STAGED`, and `PICKED_UP`.
- **Stock & Tier Pricing Management**: Fast updates for stock availability, pack sizes, bulk pricing, and minimum order quantities.
- **Depot Handover Scanner**: Barcode scanning for fast consignment release to designated Wayno fleet riders.
- **SLA & Reliability Analytics**: Daily fulfillment throughput, packing time averages, and stockout metrics.
