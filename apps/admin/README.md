# Wayno Admin Operations Hub (Next.js)

Executive command center uniting order pipeline monitoring, search engine benchmarks, business rules configuration, NFR compliance audits, and live architectural flow runners.

## Capabilities
- **Order Pipeline & Telemetry Stream**: System-wide live order state transitions and emergency overrides.
- **Search Engine Benchmark**: 16 search specification evaluators, fuzzy phonetic matcher, and automated test runners.
- **Business Rules Matrix**: 14 automated FMCG rules validator (splits, timeouts, dynamic pricing, minimums).
- **Non-Functional Requirements (NFR)**: P95 latency simulation, SLA error budget tracking, and DR failover drills.
- **Architecture Workspace**: Dynamic microservices blueprint, telemetry monitoring, and end-to-end execution flows.
