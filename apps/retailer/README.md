# Wayno Retailer Mobile App (React Native)

Mobile application designed for dukas, kiosks, and retail shop owners in Nairobi and East Africa.

## Core Capabilities
- **Fast Multilingual Catalog Search**: Typo-tolerant FMCG product catalogue search with Swahili & Sheng slang parsing.
- **1-Tap M-Pesa STK Push Checkout**: Seamless, instant mobile money checkout integration.
- **Live Order Tracking**: Stage-by-stage real-time visibility from depot staging to doorstep rider arrival.
- **Offline-First Order History**: Local SQLite caching ensuring access during patchy 2G/3G network conditions.
