# Wayno Rider Mobile App (React Native)

Dedicated courier application for motorbike (boda-boda) and van drivers executing multi-stop depot pickups and doorstep deliveries.

## Features
- **Smart Route Sequencing**: Turn-by-turn navigation optimized for Nairobi traffic, road conditions, and security corridors.
- **Depot QR Handshake**: Two-way barcode verification upon staging pickup from wholesale warehouses.
- **Proof of Delivery (POD)**: Customer PIN verification, photo capture, and digital recipient signature.
- **Live GPS Telemetry**: High-frequency, battery-optimized location streaming over WebSocket/MQTT.
