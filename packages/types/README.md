# @wayno/types

Shared TypeScript domain interfaces and event schemas across all Wayno applications, services, and SDKs.

## Exports
- `Order`, `OrderItem`, `OrderState`
- `Product`, `SupplierProduct`, `WholesalerLocation`
- `Rider`, `DeliveryHandshake`, `GeoPoint`
- `TelemetryEvent`, `EventPartition`
- `SearchQuerySpec`, `BenchmarkResult`
