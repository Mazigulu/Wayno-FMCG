# Wayno Data Layer & Schemas

Database migrations, seed catalogs, GIS spatial polygons, and analytical warehouse definitions.

## Directory Layout
- `schemas/`: PostgreSQL schema definitions, partition rules, and triggers.
- `seeds/`: Nairobi wholesale depot registries, FMCG SKU catalogs, and retail duka locations.
- `gis/`: GeoJSON boundary definitions for Nairobi sub-counties and delivery zones.
